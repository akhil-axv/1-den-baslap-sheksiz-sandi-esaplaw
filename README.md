# Python Text and List Exercise

This repository currently contains a beginner-friendly Python exercise for transforming text and working with lists.

## Run

Requires Python 3.10 or newer.

```bash
python tapsirma.py
```

## Options

The script demonstrates sorting characters, reversing text, changing letter case, and clearing a list.

## Learning goals

- Read and validate console input
- Work with Python strings and lists
- Use conditionals
- Keep executable code inside a `main()` function

The repository name is a legacy name; the current exercise is a text/list practice task.
